| F9 | Клиент получает СМС-уведомления после подтверждения ставки и после открытия депозита | Интеграция с ядром СМС-сервиса |
| F10 | Сотрудники бэк-офиса депозитов и кредитов могут управлять ставками (ранее только в XLS) | Переход от XLS к централизованному хранению |
| F11 | Процесс согласования ставки по заявке реализуется в АБС | Интеграция нового функционала с АБС |
| **U** | **Удобство использования (Usability)** | |

| U2 | Применять корпоративную систему дизайна: фирменные цвета, брендированные элементы | Единый стиль с другими приложениями банка |
| **R** | **Надёжность (Reliability)** | |
| R1 | Все сервисы должны работать 24/7 | |
| R2 | Доступность систем — 99,9% | |
| R3 | Обеспечить отказоустойчивость: работа в основном ЦОД с возможностью переключения на резервный ЦОД | Резервирование на уровне инфраструктуры |
| R4 | Исключить прямую работу интернет-банка с API АБС в новом процессе | АБС перегружена, прямое API угрожает работоспособности банка |
| **P** | **Производительность (Performance)** | |
| P1 | Отклик по всем операциям должен занимать миллисекунды | |
| P2 | Устранить проблему загрузки справочных данных > 1 секунды | Распространить оптимизацию на весь новый функционал |
| P3 | Обеспечить горизонтальное масштабирование и балансировку нагрузки между серверами и ЦОД | Распределение запросов для роста нагрузки |
| P4 | Учесть, что АБС масштабируется только вертикально — минимизировать нагрузку на её БД | Компенсировать промежуточными слоями (кэш, очереди) |

| S1 | Использовать существующие в банке технологии: БД MS SQL и Oracle | |
| S2 | Новые технологии должны быть совместимы с текущими платформами, а экспертиза — доступна внутри банка | Снижение рисков и зависимости от подрядчиков |

| S5 | Предусмотреть разработку документации для дальнейшего расширения системы | Архитектурная, API, эксплуатационная документация |

| +R7 | Обеспечить равномерное распределение нагрузки между серверами и ЦОД | Горизонтальное масштабирование |
| +R8 | Подготовить архитектурную документацию, схемы интеграций, инструкции по развертыванию | Для передачи команде сопровождения |
